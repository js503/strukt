One remote server, multiple persistent terminal sessions

The EC2 host is the workspace target. Named sessions behave like tmux sessions; each owns windows and split panes that keep running when the local app disconnects.

The EC2 server owns the workspace, filesystem, and session service.

Named sessions

Backend, operations, and scratch keep running independently.

Windows and panes

Each session restores its own tabs, splits, processes, and scrollback.

tmux compatibility
