# Contributing

This repository follows the forj delivery standard.

## Default workflow

1. Write or update a spec.
2. Write or update an implementation plan.
3. Track execution in an issue.
4. Implement on a branch.
5. Open a pull request with verification and agentic review.

## Pull request expectations

- Link the spec
- Link the plan
- Link the issue
- Describe verification
- Summarize agentic review findings
