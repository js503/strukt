# AGENTS

Use forj-derived repo instructions as the governing standard for development work in this repository.

## Required order of operations

1. Read `docs/process/development-lifecycle.md`.
2. Read `docs/process/review-standard.md`.
3. Read `docs/process/merge-policy.md`.
4. Start with a spec and implementation plan unless an explicit documented exception applies.
5. Do not implement before the shaping artifacts are written and approved.

## Delivery rules

- Do not expand scope beyond the approved spec.
- Link the spec, plan, and issue in the pull request.
- Document verification in the pull request.
- Complete agentic review before merge.
